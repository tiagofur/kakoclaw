# Docs Workspace (TEMP)

Esta carpeta ya no es la fuente principal de documentacion estrategica.

## Regla actual

- `docs/` = material temporal y operativo de corto plazo.
- PRD y direccion de producto = fuera de `docs/`, en [../PRD/README.md](../PRD/README.md).
- Documentacion legacy/historica = [archive/legacy](archive/legacy).

## Estructura minima

- [TEMP/](TEMP/) trabajo activo de corto plazo.
- [archive/](archive/) historial y material no prioritario.

## Uso recomendado

1. Si un documento es para ejecucion inmediata, va a [TEMP/](TEMP/).
2. Si un documento queda obsoleto, eliminarlo.
3. Si un documento debe preservarse por contexto historico, moverlo a [archive/legacy](archive/legacy).
4. Si un documento define direccion de producto, arquitectura o estandares, actualizarlo en [../PRD](../PRD).
