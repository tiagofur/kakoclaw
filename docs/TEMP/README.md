# TEMP Docs (Corto Plazo)

Este directorio contiene documentacion operativa temporal: trabajo en curso, pre-produccion, pruebas y pendientes de ejecucion inmediata.

## Reglas

1. Solo contenido de corto plazo.
2. Si un documento se vuelve estable o estrategico, moverlo al PRD principal fuera de `docs/` o a documentacion permanente en otra ubicacion definida por el equipo.
3. Si queda obsoleto, eliminarlo.
